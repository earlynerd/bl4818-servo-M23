# Actuator documentation images

Store the maintained actuator, rework, wiring, and assembly photographs here.

| File | Shows |
| --- | --- |
| `closeup_with_connectors.jpg` | Completed actuator and end cap with RX, TX, and SWD openings |

New images should use descriptive names such as `actuator-r1-exploded.jpg` or
`bl4818-r1-ina180-rework-closeup.jpg` rather than camera-generated filenames.

Instructional images should have a caption in the referring document that
states the hardware revision, orientation, and what the reader should verify.
Keep original-resolution masters when practical; optimized web copies can be
added separately if repository size becomes a concern.
