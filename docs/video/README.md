# Demonstration video

`handpan_video_h264.mp4` is a 56-second sound-enabled demonstration of ten
actuators playing the instrument. It was re-encoded with HandBrake and contains
H.264 (`avc1`) video and AAC (`mp4a`) audio markers for broad browser
compatibility. The file is linked prominently from the main README.

The committed MP4 is approximately 36 MB. If a stable GitHub user-attachment or
release-asset URL is added later, the README target can be changed to that URL
to avoid carrying future video revisions in normal Git history.
