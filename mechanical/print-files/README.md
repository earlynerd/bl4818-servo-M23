# Ready-to-print exports

This folder currently contains AP214 STEP exports of the base, encoder cover,
and mallet holder generated by SolidWorks 2026. STEP preserves useful editable
geometry but does not encode verified slicer settings or print orientation.

Add revisioned STL or 3MF exports after confirming the actual printed
orientation and settings. Filenames should eventually include the part name and
revision, for example `base-r1.3mf`. Record the matching electronics/mechanical
revision and print settings in `mechanical/README.md` or a revision-specific
release note.
